# TowaPC Webサイト

`index.html` をブラウザーで開いて使用できます。5ページ構成で、スマートフォンにも対応しています。

## ロゴ・内容の変更

ロゴは `assets/TowaPC.svg`。同じ名前で置き換えると、ヘッダー・フッターの両方に反映されます。別形式の場合は `content.js` の `logo` を変更してください。

`content.js` に製品・お知らせ・紹介文・参加先URLをまとめています。製品とお知らせはサンプルです。

## ヒーロー

背景は `assets/hero-original.jpg`、重ねる文字は `content.js` の `headline` です。文字は選択・編集できるHTMLで表示しています。

背景はご提供の元写真をそのまま使用しています。ホームでは写真が最初からヘッダーの背後に重なります。

## 動きとデザイン

初回表示で背景がゆっくり落ち着き、見出しがフェードインします。スクロール時にカードが順に現れ、カーソルを重ねると少し浮き上がります。端末で視覚効果を減らす設定にしている場合はアニメーションを無効にします。

ヘッダー背景の不透明度は56%。色・透明度・アニメーションは `style.css` 末尾で調整できます。
