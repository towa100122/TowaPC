# TowaPC.com

TowaPCの公式Webサイトです。

「What lasts? What changes?」を掲げ、難しい未来を少し近く、手に届くようにするためのものづくりを紹介しています。

## サイトの内容

- TowaPCのProductsと開発プロジェクト
- TowaPCからのNews
- 団体の考え方、メンバー、協力関係
- TowaPC Communityへの参加方法と公式連絡先
- 利用規約とプライバシーポリシー

サイトは端末幅に応じてレイアウトが変わり、端末のライト・ダーク設定にも追従します。
