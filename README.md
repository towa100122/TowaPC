# TowaPC.com

TowaPCの公式Webサイトです。

人々が抱える、永遠と思えるような難しい課題を、少しずつテクノロジーで解決できるように。少しの発見とのびのびとした発想で、暮らしを少し豊かに、便利にしていくためのものづくりを紹介しています。

## サイトの内容

- TowaPCの製品と開発プロジェクト
- TowaPCからのお知らせ
- 団体の考え方、メンバー、協力関係
- TowaPC Communityへの参加方法と公式連絡先
- 利用規約とプライバシーポリシー

サイトは端末幅に応じてレイアウトが変わり、端末のライト・ダーク設定にも追従します。

公開先: [https://towapc.com/](https://towapc.com/)
