External Theme

外部テーマをJSONから読み込む

読み込めるのは外観設定だけです。HTML、CSS、JavaScript、外部URLは実行しません。
テーマ作成ガイドライン

versionは1、設定値はsettingsの中へ書きます。記載しない項目は現在の設定を維持します。

  • theme: light / dark
  • surface: standard / material / liquid / paper / shadowless / monochrome
  • accent: standard / lavender / mint / peach / custom
  • customColor: #から始まる6桁のカラーコード
  • corners: soft / round / precise
  • density: comfortable / compact
  • motion: standard / smooth / snappy / none
{
  "name": "My Theme",
  "version": 1,
  "settings": {
    "theme": "dark",
    "themePinned": true,
    "surface": "monochrome",
    "accent": "custom",
    "customColor": "#ffff99",
    "corners": "soft",
    "density": "comfortable",
    "motion": "standard"
  }
}
