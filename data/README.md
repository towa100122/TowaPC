# 情報の更新方法

各CSVをExcelやテキストエディターで編集すると、サイトへ反映されます。1行目の列名は変更しないでください。

- `site.csv`: トップの文章、画像、参加URL、メール、SNS
- `products.csv`: 製品
- `news.csv`: お知らせ
- `partners.csv`: 協力関係
- `members.csv`: メンバー

行を増やすと項目を追加でき、行を削除すると非表示になります。値に半角カンマや改行を含める場合は、値全体を半角のダブルクォートで囲んでください。値の中のダブルクォートは `""` と2個続けます。

`products.csv` の `type` は `app`、`web`、`project` のいずれか、`color` は `pink`、`lavender`、`mint`、`cream`、`peach` のいずれかを指定します。画像を表示しない場合やリンクを設定しない場合は、そのセルを空欄にします。

`products.csv` と `news.csv` の `id` は、半角英小文字・数字・ハイフンだけで指定し、同じファイル内で重複させないでください。お知らせの日付は `YYYY.MM.DD` 形式、外部リンクは `https://` または `http://` から記入します。

編集後はサイトのルートで `bun run check` を実行してください。製品・お知らせのIDを変更した場合は、先に `bun run sync-pages` を実行します。
